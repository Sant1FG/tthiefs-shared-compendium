# Tthief's Shared Compendium

Módulo de extensión para FoundryVTT conteniendo los compendios y macros utilizadas en mis partidas.

##  Descripción

Plugin desarrollado sobre la API de FoundryVTT que extiende las funcionalidades de iluminación mediante dos macros: "Equipar Antorcha", que permite recoger y encender la antorcha directamente desde el inventario del actor, y "Soltar Antorcha", que genera un token a los pies del actor para simular iluminación realista. El módulo incluye además un compendio con todos los personajes y objetos únicos creados para mis campañas.

##  Tecnologías

- **Lenguaje:** JavaScript
- **Plataforma:** FoundryVTT (API)

##  Características

- Macro "Equipar Antorcha": recoge y enciende la antorcha directamente desde el inventario del actor
- Macro *Soltar Antorcha": genera un token a los pies del actor para simular iluminación realista
- Compendio incluido con personajes y objetos únicos de campaña
- Compatible con la API oficial de FoundryVTT

##  Instalación

1. Accede a la última release disponible en GitHub
2. Copia la URL del atributo `manifest` dentro de `module.json`
3. Pega la URL en la pantalla de instalación de módulos de FoundryVTT
4. Activa el módulo desde la configuración de tu mundo
